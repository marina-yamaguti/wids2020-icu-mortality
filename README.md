# ICU mortality prediction — WiDS Datathon 2020

Hands-on Machine Learning final project. Members: [Member 1], [Member 2], [Member 3].

| File | Content |
|---|---|
| `project.ipynb` | The submission: code + report (Intro, Preprocessing, Training, Evaluation, Conclusion) |
| `wids_utils.py` | Helper module used by the notebook (cleaning, models, CV, metrics, plots) — submit it with the notebook |
| `requirements.txt` | Package versions used for the executed notebook (Python 3.12) |
| `docs/slides_outline.md` | Slide-by-slide outline, speaker split, likely jury questions |
| `data/raw/` | Kaggle files (**not** submitted): <https://www.kaggle.com/competitions/widsdatathon2020/data> |

Run: put `training_v2.csv`, `unlabeled.csv` (only its `hospital_id` column is read) and `WiDS Datathon 2020 Dictionary.csv` in `data/raw/`, then execute the notebook top to bottom (~12 min).
