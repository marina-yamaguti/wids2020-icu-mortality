# ICU mortality prediction — WiDS Datathon 2020

Hands-on Machine Learning final project. Members: Fatoumata OULARE, Lydia BENOSMANE, Marina GELLER YAMAGUTI.

| File | Content |
|---|---|
| `newproject.ipynb` | **The submission**: code + report (Introduction, Preprocessing, Training, Evaluation, Conclusion) |
| `homl2627_project-proposal_fatoumata_lydia_marina.ipynb` | Project proposal (already submitted) |

Run: put `training_v2.csv`, `unlabeled.csv` (only its `hospital_id` column is read) and `WiDS Datathon 2020 Dictionary.csv` in `data/raw/`, then execute `newproject.ipynb` top to bottom (about 25 minutes).
